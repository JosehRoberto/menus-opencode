# menus-opencode

Meta-repositório de **planejamento** para os menus de comandos do OpenCode.

## Propósito

Centralizar planejamentos estratégicos de futuras atualizações dos repositórios:

- [menu-antares-opencode](https://github.com/JosehRoberto/menu-antares-opencode)
- [menu-mira-opencode](https://github.com/JosehRoberto/menu-mira-opencode)
- [menu-reversa-opencode](https://github.com/JosehRoberto/menu-reversa-opencode)
- [menu-reversa-openclaude](https://github.com/JosehRoberto/menu-reversa-openclaude)

Este repositório **não** contém os artefatos executáveis desses menus — apenas o planejamento. A implementação permanece em cada repositório alvo.

## Convenção de nomes

```text
planejamento-<repo-alvo>-<tema>.md
```

Exemplo: `planejamento-menu-antares-opencode.md`.

## Planejamentos

| Arquivo | Repositório alvo | Status |
|---|---|---|
| `planejamento-menu-antares-opencode.md` | `menu-antares-opencode` | Implementado — v1.0.0 |
| `planejamento-menu-mira-opencode.md` | `menu-mira-opencode` | Implementado — v1.0.0 |
| `planejamento-menu-reversa-opencode.md` | `menu-reversa-opencode` | Proposto |

## Fluxo de trabalho

1. Registrar o planejamento neste meta-repositório.
2. Aprovar o plano.
3. Implementar no repositório alvo (a fonte de verdade do código é o repo alvo).
